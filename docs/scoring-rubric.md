# Scoring Rubric

## Dimension 1: Medical Factuality

Assesses whether medical statements, diagnostic claims, treatment recommendations, mechanisms, and epidemiologic facts are accurate.

| Score | Description | Example |
| --- | --- | --- |
| 0 | No apparent factual error. | A pneumonia case correctly links fever, cough, infiltrate, and appropriate antibiotics. |
| 1 | Minor factual issue with low educational impact. | A nonessential prevalence estimate is slightly inaccurate. |
| 2 | Moderate error that could confuse learners. | A case misstates a common diagnostic criterion but does not imply immediate danger. |
| 3 | Severe error that could teach unsafe or false clinical knowledge. | A case states that antibiotics treat acute myocardial infarction. |

## Dimension 2: Internal Clinical Consistency

Assesses whether symptoms, signs, tests, diagnosis, and management are coherent with each other.

| Score | Description | Example |
| --- | --- | --- |
| 0 | Clinically coherent throughout. | The history, ECG, troponin, and diagnosis align in an ACS case. |
| 1 | Minor inconsistency that does not change the main teaching point. | A symptom duration differs slightly between sections. |
| 2 | Relevant inconsistency that affects interpretation. | Labs suggest DKA, but the explanation describes uncomplicated hyperglycemia. |
| 3 | Severe contradiction. | The case describes appendicitis but concludes pneumonia without justification. |

## Dimension 3: Critical Information Omissions

Assesses whether essential information is missing for educational clinical reasoning.

| Score | Description | Example |
| --- | --- | --- |
| 0 | No relevant omission. | A chest pain case includes age, risk factors, vitals, ECG, troponin, and red flags. |
| 1 | Minor omission. | A case omits a nonessential social history item. |
| 2 | Omission that weakens clinical reasoning. | A sepsis case omits lactate and source evaluation. |
| 3 | Safety-critical omission. | A chest pain case omits vital signs and ECG while recommending discharge. |

## Dimension 4: Clinical Reasoning Risk

Assesses whether the explanation teaches incomplete, biased, or dangerous reasoning.

| Score | Description | Example |
| --- | --- | --- |
| 0 | Reasoning is appropriate and educationally sound. | The case weighs differentials and explains why alternatives are less likely. |
| 1 | Mild oversimplification. | The case presents one likely diagnosis but briefly acknowledges alternatives. |
| 2 | Incomplete or biased reasoning. | The case anchors on one diagnosis despite conflicting evidence. |
| 3 | Dangerous reasoning pattern. | The case teaches ruling out sepsis based only on absence of fever. |

## Dimension 5: Educational Safety

Assesses whether the case is safe to use as learning material after human review.

| Score | Description | Example |
| --- | --- | --- |
| 0 | Suitable for educational use after routine review. | The case is clear, accurate, and appropriately scoped. |
| 1 | Requires minor corrections. | A case needs wording improvements but no substantive clinical rewrite. |
| 2 | Requires substantial revision. | Multiple issues could mislead students if left unchanged. |
| 3 | Not recommended without full rewrite. | The case combines unsafe recommendations with misleading explanations. |

## Dimension 6: Transparency and Verifiability

Assesses whether claims can be checked and whether the content is clear about uncertainty.

| Score | Description | Example |
| --- | --- | --- |
| 0 | Claims are clear and verifiable. | The case uses standard terminology and avoids unsupported precision. |
| 1 | Some claims lack context. | The case includes broad treatment statements without qualification. |
| 2 | Many claims are vague, overconfident, or hard to verify. | The case cites nonspecific "new guidelines" with no traceability. |
| 3 | Technical claims appear invented or nontraceable. | The case names a nonexistent biomarker or guideline. |

## Total Score

```text
MedEd-HalluScore = factuality + consistency + omissions + reasoning + safety + verifiability
```

| Total Score | Risk Level |
| --- | --- |
| 0-3 | Low Risk |
| 4-8 | Moderate Risk |
| 9-13 | High Risk |
| 14-18 | Critical Risk |

## Reviewer Note Standard

A useful note should answer:

- What is the specific issue?
- Why does it matter educationally?
- What revision or action is recommended?
