# Limitations

MedEd-HalluScore is a structured review framework, not a substitute for clinical expertise.

## Scope Limits

- It evaluates educational clinical cases, not real-time clinical decision support.
- It does not validate an LLM for patient care.
- It does not determine whether a medical treatment is appropriate for a specific patient.
- It does not replace institutional review, curriculum governance, or faculty oversight.

## Evidence Limits

The current sample dataset is illustrative and should not yet be treated as a validated benchmark. The sample dataset is illustrative and should not be treated as a validated benchmark.

Future work should evaluate:

- Inter-rater reliability
- Generalizability across specialties
- Reviewer training requirements
- Sensitivity to case complexity
- Alignment with expert educational safety judgments

## Reviewer Dependence

Scores depend on reviewer expertise, context, and interpretation. Cases involving advanced specialty knowledge should be reviewed by appropriately qualified experts.

## Model Dependence

LLM behavior changes over time. A case generated by a specific model on a specific date may not represent the current behavior of that model.

## Recommended Disclaimer

Educational institutions using this framework should clearly state that AI-generated clinical cases require human review before use with learners.
